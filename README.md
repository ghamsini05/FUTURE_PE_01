# AI Website Copy Generator for Luxury Photography Brands

## Project Overview

This project demonstrates the use of Prompt Engineering and AI-assisted content generation to create premium website copy for a luxury photography brand named “Élan Studio”.

The project focuses on generating elegant, emotionally engaging, and conversion-focused website content tailored for modern luxury clients using structured AI prompts.

* personal branding photography
